# 공개 표시 이름 보호

2026-10-27 운영 DB에 `community-display-privacy.sql`의 기본값 변경을 적용했습니다.

- 확인용 게시글 1개와 댓글 1개의 작성자명, 해당 계정의 표시 닉네임을 가명으로 정정했습니다.
- 해당 계정의 인증 메타데이터와 연결 프로필에서 불필요한 이름·프로필 이미지 필드를 정리했습니다. 로그인 식별자·이메일·인증 수단은 유지했습니다.
- 정정 후 public 스키마의 모든 기본 테이블 텍스트·JSON·배열 열을 해당 계정의 이름·이메일·전화번호와 비교했으며 추가 일치 항목은 없었습니다. 개인정보 원문은 점검 보고서나 코드에 기록하지 않았습니다.
- 새 공개 글·댓글의 기본 작성자명은 앱에서 선택한 `dealvue_nickname`만 사용하고, 없으면 `딜뷰 이웃`을 사용합니다. 소셜 제공자의 name/full_name/이메일 앞부분은 공개 이름으로 사용하지 않습니다.
- 기존 기기 공용 닉네임 캐시는 앱 시작 시 제거합니다. 닉네임 편집은 계정 메타데이터에 저장합니다.

소스 검사, lint, TypeScript 빌드, 별도 PostgreSQL 테스트에서 실명 기본값 차단 및 댓글 CRUD·권한 검사를 통과했습니다. 로컬 Safari에서 공개 작성자명·마이페이지·프로필 편집의 가명 표시 및 저장을 확인했습니다.

DB 정정은 적용되었으며 프런트엔드 코드의 배포는 별도입니다.
