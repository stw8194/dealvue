# 관람객 관점 이용 흐름 재점검 — 2026-10-29

Safari에서 실제 화면을 누르며 점검했다. 주로 모바일 뷰포트 390×844를 사용했다. 원래 로그인 상태를 보존하기 위해 별도 localhost 주소의 전시용 계정을 병행했다. 웹 배포와 커밋은 하지 않았다.

## 발견 후 수정한 부분

1. 카탈로그의 일시적인 백그라운드 조회 실패가 예약 폼을 없애던 문제: 기존 데이터·입력 폼을 유지하고 재조회 안내를 표시한다. 최초 조회 실패에는 같은 화면에서 다시 시도할 수 있다.
2. 예약 내역 캐시 갱신 도중 새 예약이 잠시 '찾을 수 없음'으로 보일 수 있는 문제: 조회 진행 상태를 구분하고, 대상 예약이 없으면 완료 전까지 로딩으로 표시한다. 읽기 실패도 '예약 없음'과 구분한다.
3. 아래쪽 버튼을 누른 뒤 새 페이지가 아래로 스크롤된 채 열리는 문제: 새로운 경로 이동은 상단부터 보여주되 뒤로/앞으로와 해시 링크는 유지한다.
4. 공통 예약·검색 등의 화면에 뒤로 가기 버튼이 없던 부분: 공통 헤더에 버튼을 추가하고 직접 진입한 경우 홈으로 이동한다.
5. 이메일 가입 창에 명시적인 닫기/키보드 모달 처리가 없던 부분: 네이티브 dialog, 닫기 버튼, Escape 동작을 적용했다.
6. 매장 상단 평점·리뷰 수와 리뷰 탭이 서로 달랐던 부분: 실제 표시되는 등록 후기와 작성 후기 기준으로 상단을 일치시켰다. Ardien의 상단 4.8/5개 표시를 확인했다.
7. 댓글 조회 도중 '첫 댓글' 안내가 먼저 나오던 부분: 댓글 로딩과 실제 빈 목록을 구분했다.
8. 찜 화면의 인증 초기화 중 로그인 안내가 먼저 보이던 부분: 초기 확인 상태를 표시한다. 기기 찜이 자동으로 계정 동기화되는 것으로 오해할 수 있는 로그인 홍보 문구도 정리했다.
9. 우리동네에서 연 운세·룰렛을 닫으면 원래 화면 대신 놀이터 홈에 남던 부분: 진입 출처를 유지해 우리동네로 복귀시켰다. 드레스룸 내부 모달은 기존처럼 놀이터로 닫힌다.
10. 딜키트에 노출되던 '예약 점유', '기준(임시)' 표현: 예상 소요 시간과 이동시간 안내로 정리했다. 예약 시간 계산은 변경하지 않았다. 여러 매장 패키지의 총 예상 시간 표시에는 이동시간을 포함시켰다(시술 120분 + 이동 30분 = 150분).

11. 홈 최초 타임딜 조회 실패가 빈 영역처럼 보이던 부분: 오류 안내와 같은 화면의 재조회 버튼을 추가했다.

## 아직 완성됐다고 볼 수 없는 부분

- **서버 예약의 방문 완료·리뷰 작성 연결:** 현재 리뷰 편집과 방문 완료 처리는 기존 기기 예약용이다. 새 서버 예약에서 이용을 마친 뒤 같은 기능을 제공하려면 별도 연결이 필요하다. 미래 예약 테스트를 위해 운영 시간을 조작하거나 실제 예약을 강제로 완료시키지 않았다. 이는 코드에서 확인한 기능 제한이며 이번에 해결하지 않았다.
- **드레스룸의 친구찾기·레벨 쿠폰:** 이전에 요청한 화면 프로토타입 상태다. 실제 친구 계정 연결과 10레벨 쿠폰 발급은 구현된 기능으로 볼 수 없다.
- **동기화 범위:** 신규 예약·커뮤니티·발급 쿠폰은 서버 기능을 사용한다. 아바타/놀이 포인트/기기 찜 등 기존 기기 저장 기능이 모두 다른 기기로 동기화되는 것은 아니다.
- 신규 가입 완료와 카카오·구글 인증 왕복, 신규 공개 글·댓글 저장, 룰렛 추첨, 실제 휴대폰 키보드/회전/저속망의 모든 조합을 이번 화면 점검에서 완료했다고 주장하지 않는다.

## 평가

직접 진행한 예약 생성·변경·취소와 다른 계정의 시간 차단/해제는 통과했다. 탐색·쿠폰·찜·커뮤니티 조회·놀이터의 주요 이동도 확인했고 흐름을 끊던 문제를 수정했다. 다만 위에 적은 리뷰 연결과 프로토타입 기능이 남아 있어 '앱 전체의 모든 기능이 완성됐다'고 판단하지 않는다.

## 최종 재검사

- lint, TypeScript 포함 production build, `git diff --check` 통과. 기존 큰 JS 청크 경고는 남아 있으나 빌드 실패는 아니다.
- 공유 조회 중첩/재시도/백그라운드 중단, 카탈로그 요청 수/자정/캐시 만료, DB 예약 충돌/변경/취소/패키지 원자성, 커뮤니티 저장/댓글/좋아요/필터 격리 테스트 통과.
- 화면에서 딜키트 총 150분(이동 30분 포함), 취소 내역의 예약 7, 전시용 계정의 예정 예약 없음까지 확인했다.
- 테스트 계정에는 이번에 받은 첫방문 쿠폰 1개와 운세 5P가 남는다. 기존 사용자 계정의 예약·쿠폰·포인트·착용 외형은 변경하지 않았다. 새 공개 글·댓글은 등록하지 않았고, 시험한 좋아요와 매장 찜은 원복했다.
