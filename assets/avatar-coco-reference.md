# 아바타 얼굴 기준: 코코 원본

얼굴 기준은 `public/images/playground/cute-fashion-atlas-v3.png`의 첫 번째 코코 단발 원화다. 코코의 얼굴을 다른 공통 얼굴로 교체해서 헤어를 통일하면 안 된다. `avatar-face-base.png` 또는 새로 생성한 얼굴을 캐릭터의 기준으로 사용하지 않는다.

- 코코 정면의 기본 얼굴·미소는 기존 `OriginalPortrait` 렌더링 그대로 유지한다.
- 다른 헤어는 `CocoFace.tsx`에서 코코 원화의 얼굴을 고정된 512×768 좌표로 가져온다. 이마·목이 더 드러나는 부분도 코코 원화의 깨끗한 피부 부분을 사용한다. 눈·코·입 부분은 피부 경계 혼합에서 제외한다.
- 측면과 사선의 얼굴은 같은 코코 원화의 방향별 이미지 첫 번째 셀을 사용한다. 회전 중에는 원화의 기본 표정을 사용한다.
- 코코 외 5종은 `assets/hair-redesign-v3/`의 새 헤어 원화를 사용한다. 사용자 선택에 따라 풍성한 컬과 리본을 코코의 머릿결·색감에 맞췄다. 방향별 헤어 배치만 조정하며, 얼굴의 크기·좌표는 유지한다. 현재 구현은 방향별 원화 합성이다.
- 코코와 다른 헤어 모두 8방향 회전을 사용한다. 회전 시간은 730ms다.

검증은 `scripts/check-coco-avatar.mjs`와 `scripts/review-coco-heads.mjs`로 실행한다. 두 스크립트는 `DEALVUE_TEST_URL`과 필요시 `DEALVUE_PLAYWRIGHT_MODULE`을 받는다.

첫 검사는 코코 전체 그림이 원본과 픽셀 단위로 같은지 확인한다. 나머지 헤어의 눈·코·입은 원래 좌표에서 비교하며, 원화의 반투명 픽셀 합성에 따른 RGB 1단계 반올림만 허용한다. 이후 실제 화면에서 여섯 헤어의 8방향 옷 변경을 확인한다. 두 번째 스크립트는 정면·측면·사선·후면과 입 모양 비교 이미지를 만든다. 테스트 통과와 별개로 실제 화면의 헤어 경계, 목 연결, 피부색, 머리색을 육안으로 확인해야 한다.


## v4 원화 재제작으로 대체

아래 기록의 v3 얼굴 패치·헤어 구멍 합성은 현재 비코코 헤어에서 사용하지 않는다. 코코 원본은 보존하고, 나머지 5종은 얼굴·귀·목을 포함한 완성형 머리 원화로 다시 제작했다. 현재 구현과 실제 생성 프롬프트는 [avatar-heads-v4/README.md](./avatar-heads-v4/README.md)를 참조한다.
