# 코코와 어울리는 인형 헤어 5종

사용자 선택: **귀여운 인형 느낌, 풍성한 컬과 리본, 코코와 같은 질감.** 코코 단발과 승인된 얼굴은 수정하지 않았다.

[앱 적용 비교 화면](./preview-front.png)

이미지는 **내장 image_gen 도구**로 제작했다. 각 PNG는 같은 헤어의 정면·정면 사선·측면·후면 사선·후면을 담은 투명 배경 원본이다. 아래 원본 파일과 [정확한 생성 프롬프트](./prompts.json)를 보관한다.

- [벨벳 웨이브](./waves-turns.png)
- [리본 트윈테일](./twintails-turns.png)
- [리본 브레이드](./braids-turns.png)
- [리본 더블번](./bun-turns.png)
- [베이비 컬 쇼트](./pixie-turns.png)

참고 화면은 [코코 원본 5방향](./coco-turn-reference.png)이다. 얼굴·피부·눈·입은 새 헤어 원본에 포함하지 않고, 앱에서 기존 `CocoFace`를 그대로 사용한다.

앱은 `public/images/playground/hair-v3/*-turns.webp`를 읽는다. `scripts/build-hair-redesign.mjs`가 PNG의 크기와 배치를 바꾸지 않고 WebP로 내보낸다. 다섯 파일 합계는 약 1.9MB이며, 회전 전에 현재 헤어의 한 파일을 디코딩한다.

`HairArtwork.tsx`의 좌표는 이미지에서 헤어만 잘라 코코의 고정된 512×768 좌표에 배치한다. [배치 기록](./placements.json)은 이 좌표와 같다. 얼굴 위치·크기는 바꾸지 않는다. 낮은 알파의 생성 잔여물은 렌더링 필터로 제거한다. 리본과 컬의 형태는 생성 원화 그대로 유지한다.

검수: `scripts/review-coco-heads.mjs`, `scripts/check-coco-avatar.mjs`, `scripts/check-avatar-appearance.mjs`. 원본 코코의 전체 픽셀 동일성, 다른 헤어의 얼굴 좌표·픽셀 보존, 8방향 회전, 저장·불러오기와 화면 크기별 표시를 확인한다.

## 리본 없는 버전

추가 요청에 따라 5종 모두 장식 없는 버전을 제작했다. 내장 `image_gen` 편집으로 리본에 가려진 부분을 같은 질감의 머리카락으로 채웠다. 원래의 리본 버전도 유지하며, 앱의 **얼굴·헤어**에서 각각의 카드로 선택한다. 코코 단발과 리본 없는 5종, 리본 있는 5종을 합쳐 총 11개 카드가 보인다.

- 원본: [웨이브](./no-ribbon/waves-turns.png), [트윈테일](./no-ribbon/twintails-turns.png), [브레이드](./no-ribbon/braids-turns.png), [더블번](./no-ribbon/bun-turns.png), [컬 쇼트](./no-ribbon/pixie-turns.png)
- [편집 프롬프트와 입력·출력 기록](./no-ribbon/prompts.json)
- [앱 적용 비교 화면](./no-ribbon/preview-front.png)

앱용 파일은 `public/images/playground/hair-v3/no-ribbon/*-turns.webp`에 저장한다. 동일한 배치 좌표를 사용하며 얼굴 그림은 수정하지 않는다. 선택한 헤어는 외형 및 코디북에 함께 저장한다. 기존 저장 데이터는 리본 버전을 유지한다.

리본 없는 버전 검수는 `DEALVUE_HAIR_RIBBON=none`으로 `review-coco-heads.mjs`와 `check-coco-avatar.mjs`를 실행한다.

## 얼굴과 헤어 접합 수정

앞면 그림의 빈 얼굴 영역을 뒤쪽에도 복제하던 구조를 수정했다. `HairBacking`이 같은 헤어의 후면 원화에서 뒷머리를 그린 뒤, 그 위에 원본 코코 얼굴과 앞머리를 겹친다. 턱 아래와 볼 옆이 배경색으로 뚫리는 문제를 해결하며, 정면 사선에서는 이마 확장 패치가 얼굴 밖으로 각지게 드러나지 않도록 경계를 제한한다. 얼굴의 눈·코·입 원본은 변경하지 않는다.

## 더블번 배치 보정

구름 더블번과 리본 더블번의 정면·정면 사선 그림을 위쪽과 얼굴 중심 쪽으로 조정했다. 눈을 덮던 앞머리를 올리고, 더블번에 맞는 뒷머리 마스크와 너비를 사용해 볼·턱 옆의 큰 빈틈을 줄였다. 코코 얼굴의 크기와 좌표, 다른 헤어의 배치는 변경하지 않았다. Safari에서 두 종류의 다섯 방향을 나란히 표시해 비교했다.

## 팔과 헤어 순서

`Avatar.tsx`에서 몸통 → 헤어·얼굴 → 팔·소매 → 장신구 순서로 겹친다. 팔 레이어는 현재 의상의 원화를 재사용하며 정면·사선·측면·후면마다 소매와 손 위치를 따라 분리한다. 긴 머리는 가슴과 등 위에 남겨 두고 팔만 앞에 표시한다. 측면 어깨는 정면의 수평 절단선을 사용하지 않는다.

뒷머리와 턱이 만나는 경계에는 작은 알파 혼합을 적용했다. 웨이브 정면의 오른쪽 절단 범위를 좁혀 옆 셀의 가느다란 조각이 보이지 않도록 했다. 코코 얼굴과 헤어 선택·저장 방식은 유지한다.

`scripts/check-avatar-hair-layering.mjs`는 긴 헤어 3종과 의상 6종 및 다섯 방향의 대표 조합 26개를 비교한다. 원본 의상의 팔이 보이는 픽셀을 복원하는지 확인하며, 반투명 가장자리는 별도로 처리한다. `check-coco-avatar.mjs`의 원본 얼굴 검사도 함께 실행한다.
