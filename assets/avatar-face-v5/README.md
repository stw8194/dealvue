# 얼굴 표현·의상 경계 보정 v5

입술 원화 `mouths.png`는 내장 image_gen으로 코코 원화를 참조해 제작했다. 실제 프롬프트는 [generation-record.json](./generation-record.json)에 보관한다. 기본 미소는 각 헤어 원화의 입을 유지하고, 다른 표정은 이 원화를 작게 표시한다. 원래 입을 가릴 때는 해당 헤어의 동일 얼굴에서 인접 피부를 가져오며, 다른 얼굴의 피부를 붙이지 않는다.

홍채 좌표는 눈 전체의 어두운 픽셀 중심과 구분한다. 기존 좌표는 속눈썹까지 포함해 실제 홍채보다 위에 있었다. Safari에서 SVG hueRotate 필터를 사용해 홍채 영역만 변경한다. 피부 톤은 과한 색상 회전 대신 작은 밝기·채도 차이로 조정한다. 눈 주변을 원형 피부 패치로 덮어 복원하지 않는다.

의상과 앞쪽 팔 레이어에 같은 의상 윤곽을 적용한다. 이전 팔 레이어가 의상에 그려진 예전 머리까지 다시 보여주는 문제도 방지한다. 코코 머리에 있던 사각형 어깨 노치는 제거했다. 기본 니트는 원화에서 측정한 목·칼라·어깨 윤곽을 사용하고, 나머지 의상은 각 원화에서 측정한 경계와 여유 폭을 사용한다. 생성 스크립트는 `scripts/prepare-avatar-face-v5.py`, 실제 데이터는 `src/data/avatar-face-v5.json`이다. 원본 의상 그림은 수정하지 않는다.

헤어밴드 3종, 티아라, 왕관과 각 색상 변형은 목록·착용·구매에서 제외했다. 기존 소장 기록과 ID는 보존한다.

Safari에서 기본 니트의 코코·웨이브·브레이드 표정, 트윈테일 눈 색 5종, 더블번 피부 톤 4종, 쇼트 헤어와 의상 36벌을 비교했다. 모든 헤어×의상×표정×색 조합을 전수 검수한 것은 아니다. 회전 중 얼굴은 기존 방향별 원화를 유지한다.
